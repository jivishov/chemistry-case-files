Honors · estimating maximum uncertainty

For this activity, estimate the maximum relative uncertainty in density by adding the relative uncertainties in mass and volume. Then compare that uncertainty with the difference between possible metal densities and decide whether the measurement supports an identification.

For the same absolute reading uncertainty, a smaller sample has a larger relative uncertainty. A larger sample can make nearby density values easier to distinguish.

Accuracy describes how close a measurement is to an accepted or reference value. Precision describes how closely repeated measurements agree with one another. Repeated measurements help evaluate precision; comparison with a reference value is needed to evaluate accuracy.
