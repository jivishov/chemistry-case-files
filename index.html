Chemistry connects particle structure and interactions to the properties and changes we can observe. In each unit, you will use models, measurements, calculations, and data to build a scientific explanation.

Each investigation includes an applied Case File based on a real event, technology, or scientific problem. Optional Honors work adds more quantitative reasoning and modeling without changing the core learning path.

How to work through a unit

Follow the evidence path

  1. 01

    Start with the guiding question. Identify the chemical idea you need to explain.

  2. 02

    Run the investigation. Use observations, models, and calculations to test your thinking.

  3. 03

    Support a conclusion. Connect your claim to the evidence you collected.

  4. 04

    Open the Case File. Apply the same chemistry to an authentic situation.

Build from measurement to nuclear change

The sequence begins with reliable measurement and atomic structure, then develops the relationships among bonding, quantity, reactions, energy, and the behavior of matter.
